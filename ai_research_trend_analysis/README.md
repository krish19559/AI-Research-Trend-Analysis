# AI Research & Trend Analysis

A reproducible research-analysis project comparing AI opportunities across education, media, fashion, music and social-impact use cases.

## Features
- Structured dataset
- AI trend categorization
- Transparent opportunity scoring
- Opportunity ranking
- Markdown report generation

## Run
```bash
python -m venv .venv
pip install -r requirements.txt
python analyze.py
```

Generated file:
`reports/ai_trend_report.md`

This is a transparent portfolio research model, not an industry-wide benchmark.
